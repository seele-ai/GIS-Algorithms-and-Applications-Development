# 邻近分析工具箱（Proximity）

这里放**邻近分析工具箱**里的工具：一个工具 = 一个继承 `GIS.Toolbox.UI.ToolFormBase` 的界面类（命名空间建议
`GIS.Toolbox.Tools.Proximity`），然后在 `ToolCatalog.RegisterDefaults(...)` 里登记一行：

```csharp
box.AddTool(ToolBoxControl.ProximityCategory, "工具名", map => new GIS.Toolbox.Tools.Proximity.XxxToolForm(map), "一句话说明");
```

可放的工具（示例）：缓冲（Buffer）/ 泰森多边形（Thiessen）/ 最近要素（Nearest）/ 点距统计。

界面骨架直接照抄 `UI/TemplateToolForm.cs`；输入项顺序与校验规则见工程根目录的 `README.md`。

## 已实现功能

本目录现已实现三个参考 ArcGIS Pro 参数语义的邻近分析工具，均已登记到 `ToolCatalog` 并可从主程序右侧工具箱直接打开。

| 工具 | 输入 | 主要参数 | 输出 |
|---|---|---|---|
| 缓冲区（Buffer） | 点、线、面及其复合类型 | 固定/字段距离、负面缓冲、单位与方法、线单侧和端头、仅面外部、三种融合 | 面图层；未融合时保留来源属性并写入 `ORIG_FID`、`BUFF_DIST`，融合时省略两字段 |
| 泰森多边形（Thiessen） | 点 | 仅输出编号或复制全部字段；默认边界或当前地图范围 | 面图层；默认外边界为输入点范围向外扩展 10% |
| 多环缓冲区（Multiple Ring Buffer） | 点、线、面及其复合类型 | 距离列表、单位与方法、距离字段、非重叠环/重叠圆盘、仅面外部 | 面图层 |

算法主体在 `ProximityEngine.cs`：项目自有 `GIS.Geometry` 与 NetTopologySuite 的 OGC 二维几何对象相互转换，缓冲、融合和差运算使用稳定的拓扑实现，泰森多边形使用 Delaunay/Voronoi 构造并裁切到规定范围。圆弧按每四分之一圆 12 段逼近。

距离单位支持输入坐标单位、米、千米、厘米、毫米、英尺、码、英里、海里和十进制度。计算方法可选自动、平面或“测地线（球面近似）”：自动模式下投影坐标使用平面方法，`EPSG:4326/4490` 经纬度使用测地线近似；图层缺少坐标系标识、但坐标范围疑似经纬度时不会静默推断，用户必须明确选择测地线近似或先定义坐标系。测地线近似在要素中心建立局部等距方位投影，距离使用米，点缓冲半径为严格球面距离，线面缓冲为区域尺度的局部等距近似。跨越 180° 日期变更线的要素会被拒绝并给出提示。

普通缓冲支持从数值字段逐要素读取距离；面图层允许负距离，线图层支持左侧/右侧/两侧以及圆头/平头/方头。未融合结果的 `BUFF_DIST` 保存实际计算单位中的距离：平面方法为输入坐标单位，测地线近似为米。单个空几何、无效距离或计算失败不会终止整批任务，工具会跳过并汇总原因。邻近分析一次只处理一个图层；“当前已选要素”可以作为子集输入，但选择必须来自同一图层。

泰森多边形仍按二维坐标执行 Delaunay/Voronoi 构造；经纬度或未定义坐标系的输入会在运行结果中显示明显风险提示，正式距离分析建议先投影。坐标重复点保留第一条并统计，空点或非有限坐标会跳过并报告。

多环缓冲的“非重叠环（默认）”与 ArcGIS Pro 的 `Dissolve_Option=ALL` 对应：同一距离的缓冲区先融合，每个较大距离再减去上一距离范围；“重叠圆盘”与 `NONE` 对应：每个输入要素、每个距离各保留一个完整缓冲面。“仅保留输入面外部”仅对面图层开放。输入距离会去重并按从小到大执行，结果区会显示规范化后的距离和重复数量；单次要素—距离计算失败会跳过并汇总原因。
