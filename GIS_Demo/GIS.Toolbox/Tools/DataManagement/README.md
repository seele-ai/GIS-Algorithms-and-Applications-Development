# 数据管理工具箱

前六个工具已按课程顺序注册在 ToolCatalog：

1. 要素包络矩形转面：每个点、线、面生成轴对齐包络矩形。
2. 最小边界几何：最小面积矩形、最小宽度矩形、凸包、圆形、包络；支持逐要素或全部输入分组。
3. 要素转线：提取面内外环或接收线，交点处分割，重叠线段去重。
4. 要素转点：默认质心，可选内部点。
5. 要素转面：对线和面边界构建节点后生成闭合面，开放线无闭合区域时提示。
6. 要素折点转点：所有折点、沿部件长度中点、起点、终点、起终点；多部件及内外环分别处理。

## 实现

- `DataManagementEngine.cs`：NetTopologySuite 二维平面算法，返回新的 FeatureClass，不改动输入。
- `DataManagementToolForm.cs`：统一参数页、输入与输出校验、地图图层及运行日志。
- 指定图层存在选择集时仅处理已选要素，否则处理整层。当前选择可跨层，但字段和坐标系必须一致。
- 逐要素结果复制输入属性并增加 ORIG_FID；聚合结果使用 SOURCE_IDS 记录来源。本次输入序号从 0 开始，同名字段自动追加后缀。
- 输出继承输入坐标参考；所有几何计算均为平面计算。地理坐标不能直接用于地面距离、面积量测，应先投影。
- 圆为外切 128 边形近似；点或共线输入的退化边界使用微小容差扩展为面，并在日志标明。
- 所有折点模式保留闭合环的重复终点，所以闭合环起止点记录会重合。
- 输出添加至地图内存图层，持久化需使用导出要素。

## 数据管理最后三项（白宇丹）

工具位于右侧“数据管理工具箱”底部：多部分到单部分、在折点处分割线、概化。
选择输入图层；图层有选择集时仅处理已选要素，否则处理全层。填写不重复的输出图层名，运行后结果自动加入地图。输出继承属性、SRID、投影及地理基准，不修改原数据。

- 多部分到单部分：MultiPoint、MultiLineString、MultiPolygon 按部件拆分。普通要素输出独立副本；孔洞仍属于原面。
- 在折点处分割线：线及面的各内外环按相邻顶点生成两点线段，含闭合边。重复顶点造成的零长度段跳过。不在交点处额外打断。
- 概化：迭代 Douglas-Peucker 算法，最大允许偏移量使用输入坐标单位（经纬度为度）。0 保留全部顶点。线端点保留；闭环分两段处理并保持闭合；输出顶点为原顶点子集。不自动修补无效结果，以避免新增顶点；如结果无效或退化，则回退到该输入要素原几何并报告数量。不保证不同要素之间公共边界的拓扑一致性。
- ORIG_FID 为本次输入的从0开始的序号，非永久数据库ID；已有同名字段时使用后缀，保留原字段。
