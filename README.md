# GIS软件模块设计与分工（小组作业）

使用 C# 开发一款简易 GIS 软件，实现：交互式数据录入、外部数据导入导出、PostGIS 数据管理、图形基本显示（漫游/缩放）、鼠标交互选择（点选/框选）、符号及属性管理。

小组分工见《0915汇报.pptx》，五个模块的调用链：

```
1 数据结构/投影 → 2 地图显示 → 3 图层渲染 → 4 数据编辑/IO ↔ 5 PostGIS
```

## 协作约定

- 模块 1 的类库（`GIS/`）是全组共用的数据结构基础，核心接口（`Geometry`/`Feature`/`FeatureClass`/`Layer`/`Envelope`）已在分工 PPT 中约定；对接说明见 [模块1_数据结构与投影_王小宇/README.md](模块1_数据结构与投影_王小宇/README.md)，各模块改动接口前请先在小组内同步。
- `bin/`、`obj/`、`.vs/` 等编译产物不入库（已配置 .gitignore）。
- 各模块在自己的文件夹内开发，跨模块改动先与对应成员沟通。
